# Sequential SS3 tools: `sstruth` → `ss3diags`

**Workflow mode:** set `SSTRUTH_WORKFLOW_MODE` to `prototype` (default) or `production`. See `?workflowMode`.

- **sstruth** — scenario setup, retros, projections, grids, ensemble extraction (`?ss3Workflow` if available).
- **ss3diags** — diagnostics on `SS_output`: https://github.com/jabbamodel/ss3diags

Install ss3diags: `remotes::install_github("jabbamodel/ss3diags")`
